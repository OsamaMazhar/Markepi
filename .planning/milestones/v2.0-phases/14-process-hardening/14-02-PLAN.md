### A. precheckWorktreePath(worktreePath, repoRoot, deps = {})

**Parameters:**
- `worktreePath` — absolute path to check (e.g., `/tmp/worktree-agent-14-01`)
- `repoRoot` — absolute path to repo root for git operations
- `deps` — optional: execGit, existsSync (fs.existsSync default), statSync (fs.statSync default), readFileSync, rmSync, readdirSync

**Logic (fail-safe — prefer false positive "occupied" over false negative "clean"):**

1. Check if `worktreePath` exists on disk via `existsSync`. If NOT: return `{ ok: true, status: 'clean', reason: 'directory_does_not_exist', path: worktreePath }`
2. Get `git worktree list --porcelain` entries via `readWorktreeList(repoRoot, { execGit })` (reuse existing function). Build Set of listed paths.
3. Determine staleness:
   - **Orphaned:** `worktreePath` exists on disk but NOT in listed paths Set → status: `'stale'`, reason: `'orphaned_directory'`
   - **Missing .git:** `worktreePath` IS in listed paths but `.git` file missing at `${worktreePath}/.git` → status: `'stale'`, reason: `'missing_git_file'`
   - Otherwise: status: `'occupied'`, reason: `'valid_worktree'`
4. If stale (either case):
   - Run `git worktree prune` (reuse `executeWorktreePrunePlan` or inline: `execGit(['worktree', 'prune'], { cwd: repoRoot })`)
   - Check if `worktreePath` is safe to remove: read directory contents. If directory is empty OR contains only `.planning/` directory with no non-GSD files, it's safe. Use `readdirSync(worktreePath)` — if the only entries are `.planning` or the directory is empty → safe.
   - If safeto remove: `rmSync(worktreePath, { recursive: true, force: true })`. Return `{ ok: true, status: 'stale_pruned', reason: originalReason, path: worktreePath }`
   - If NOT safe to remove (contains non-GSD files like source code, node_modules, etc.): return `{ ok: false, status: 'stale_unremovable', reason: 'directory_contains_non_gsd_artifacts', path: worktreePath }`
5. If NOT stale (occupied valid worktree): return `{ ok: true, status: 'occupied', reason: 'valid_worktree', path: worktreePath }`
6. Wrap in try/catch: any unexpected error → `{ ok: false, status: 'error', reason: err.message, path: worktreePath }`

**Idempotency:** After a successful `stale_pruned`, the directory no longer exists. A second call hits step 1 (directory_does_not_exist) → `clean`. Per user decision: "second run is a no-op".

### B. addWorktreeSafe(basePath, agentId, repoRoot, branch, deps = {})

**Parameters:**
- `basePath` — parent directory for worktrees (e.g., `$TMPDIR`)
- `agentId` — unique agent identifier (e.g., `14-02`)
- `repoRoot` — absolute repo root
- `branch` — branch name to check out (e.g., `worktree-agent-14-02-x9k2`)
- `deps` — optional: execGit, existsSync, precheckWorktreePath (inject for testing)

**Logic:**

1. Construct primary path: `primaryPath = path.join(basePath, 'worktree-agent-' + agentId)`
2. Run `precheckWorktreePath(primaryPath, repoRoot, deps)`:
   - If `stale_pruned` or `clean`: proceed to step 3
   - If `occupied`: go to fallback (step 4)
   - If `stale_unremovable` or `error`: return `{ ok: false, path: primaryPath, fallbackUsed: false, reason: precheckResult.reason, manifestEntry: null }`
3. Run `git worktree add <primaryPath> <branch>` via execGit. If exitCode 0: return `{ ok: true, path: primaryPath, fallbackUsed: false, reason: 'primary_path_used', manifestEntry: { worktree_path: primaryPath, branch, agent_id: agentId } }`
4. If step 3 fails with "already exists" (stderr contains "already exists" or "already checked out" or exitCode != 0): construct fallback path.
   - Fallback: `fallbackPath = path.join(basePath, 'worktree-agent-' + agentId + '-' + String(Math.floor(Date.now() / 1000)))`
   - Run `precheckWorktreePath(fallbackPath, repoRoot, deps)`:
     - If `clean`: run `git worktree add <fallbackPath> <branch>`. If succeeds: return `{ ok: true, path: fallbackPath, fallbackUsed: true, reason: 'fallback_path_used', manifestEntry: { worktree_path: fallbackPath, branch, agent_id: agentId } }`
     - If `occupied` or `stale_unremovable`: return `{ ok: false, path: fallbackPath, fallbackUsed: false, reason: 'both_paths_occupied', manifestEntry: null }`
5. If fallback `git worktree add` also fails: return `{ ok: false, path: fallbackPath, fallbackUsed: false, reason: 'git_worktree_add_failed', manifestEntry: null }`

Per user decision: "If both primary and fallback paths occupied: fail immediately with clear error". The returned `reason: 'both_paths_occupied'` with `ok: false` satisfies this.

# Per D-02/D-03: detect and prune stale worktree directories before git
# worktree add to prevent "already exists" failures.  Idempotent — safe to
# run even when the orchestrator is re-entrant.
if [ "${USE_WORKTREES_FOR_PLAN:-true}" != "false" ]; then
  # Pre-check the worktree root for stale agent directories.  The worktree
  # root is the parent directory where isolation="worktree" creates
  # worktree-agent-* directories (CLAUDE_CODE_WORKTREE_ROOT or TMPDIR).
  WT_ROOT="${CLAUDE_CODE_WORKTREE_ROOT:-${TMPDIR:-/tmp}}"
  # Scan for any existing worktree-agent-* paths that may conflict with the
  # agent this wave is about to spawn.  The precheck command returns JSON:
  #   { ok, status: 'clean'|'stale_pruned'|'occupied'|..., reason, path }
  for WT_CANDIDATE in "$WT_ROOT"/worktree-agent-*; do
    [ -e "$WT_CANDIDATE" ] || continue
    PRECHECK=$($GSD_SDK query worktree.precheck "$WT_CANDIDATE" 2>/dev/null || echo '{"ok":false,"status":"error","reason":"sdk_call_failed"}')
    PRECHECK_OK=$(echo "$PRECHECK" | jq -r '.ok // false')
    PRECHECK_STATUS=$(echo "$PRECHECK" | jq -r '.status // "error"')
    if [ "$PRECHECK_STATUS" = "stale_pruned" ]; then
      echo "[worktree] Pre-check pruned stale worktree: $WT_CANDIDATE"
    elif [ "$PRECHECK_OK" != "true" ] && [ "$PRECHECK_STATUS" != "clean" ]; then
      echo "[worktree] Pre-check warning for $WT_CANDIDATE: $PRECHECK_STATUS — $(echo "$PRECHECK" | jq -r '.reason // "unknown"')"
    fi
  done
fi
