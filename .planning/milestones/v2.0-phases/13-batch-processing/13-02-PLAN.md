    NEW METHODS:

    1. processBatch() async
       - Guard: renderingState == .idle, photos.count > 1, else return
       - Set renderingState = .batchProcessing(current: 0, total: photos.count, eta: nil)
       - Build [BatchProcessor.BatchItem] from self.photos:
         For each photo: BatchItem(id: photo.id, sourceURL: photo.sourceURL, mediaType: photo.mediaType, overrideConfig: perItemOverrides[photo.id])
       - Request background execution time via UIApplication.shared.beginBackgroundTask with expiration handler that calls cancelBatch()
       - Create a Task stored in batchProcessingTask:
         a. Call batchProcessor.process(items: items, sharedConfig: config, onProgress: { [weak self] current, total, eta in
              Task { @MainActor in self?.renderingState = .batchProcessing(current: current, total: total, eta: eta) }
            })
         b. On completion (task not cancelled): store batchResults, set renderingState = .done, schedule batch completion notification via scheduleBatchCompletionNotification(successCount:failureCount:), end background task
         c. On CancellationError: stay in .idle, clean up partial temp files from batchResults.successes via TempFileManager.cleanup(url:), end background task
         d. On other error: set renderingState = .error(error), end background task
       - Await batchProcessingTask?.value

    2. cancelBatch()
       - Calls batchProcessingTask?.cancel()
       - Sets batchProcessingTask = nil
       - Existing cancelVideoExport() pattern adapted for batch — state cleanup happens in CancellationError catch block of processBatch()

    3. overrideConfig(for id: UUID) -> WatermarkConfiguration
       - Returns perItemOverrides[id] ?? config (shared config fallback)

    4. setOverride(_ newConfig: WatermarkConfiguration, for id: UUID)
       - Sets perItemOverrides[id] = newConfig
       - Does NOT modify self.config (shared config unchanged per CONTEXT.md decision D7)

    5. hasOverride(for id: UUID) -> Bool
       - Returns perItemOverrides[id] != nil

    6. resetOverride(for id: UUID)
       - Removes perItemOverrides[id]

    7. resetAllOverrides()
       - Removes all entries: perItemOverrides.removeAll()

    8. scheduleBatchCompletionNotification(successCount: Int, failureCount: Int) private
       - Adapt existing scheduleCompletionNotification pattern (lines 442-478)
       - Title: "Batch Complete"
       - Body: if failureCount == 0 → "\(successCount) of \(photos.count) items watermarked"
               else → "\(successCount) watermarked, \(failureCount) failed"
       - Store batch results count in App Group UserDefaults under key "batchCompletedResultCount" for notification tap handling
       - Sound: .default
       - Trigger: nil (deliver immediately)
