## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External app → Watermark (Open In) | Files received via .onOpenURL from other apps cross the sandbox boundary |
| System file picker → Watermark | Files selected via .fileImporter cross into app sandbox |
| UIPasteboard → Watermark | Clipboard image data from potentially untrusted sources |
| PhotoKit → Watermark | Camera roll access via PHAsset fetch for "Watermark Last Photo" |
| Siri/Shortcuts → Watermark | IntentFile data passed via App Group UserDefaults from Shortcuts/Siri context |
