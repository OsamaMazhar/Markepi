      5. Return the tinted `CIImage` — scale, opacity, and positioning are handled by the existing engine for-loop (same as `.text` and `.image`).
    - Follow `ImageWatermarkRenderer` struct + static method pattern exactly.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Config JSON → SignatureInput decoder | Untrusted stroke data crosses from App Group UserDefaults/PHAdjustmentData into PencilKit |
| PKDrawing rasterization | Vector stroke data converted to raster CIImage — no external input at this stage |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | SignatureInput Codable | mitigate | Validate `PKDrawing(data:)` doesn't throw at render time in SignatureRenderer; skip corrupted layers with `continue` (no crash) |
| T-07-02 | Denial of Service | SignatureInput.strokeData | mitigate | PencilKit stroke data is vector and typically &lt;100KB per drawing; no size enforcement needed. If future abuse emerges, cap at 1MB in `addSignatureLayer`. |
| T-07-03 | Tampering | WatermarkLayer Codable (.signature case) | mitigate | `decodeIfPresent` on `signatureConfig` key — old configs without signature layers decode without error; `opacity` and `isVisible` default to 1.0 and true |
</threat_model>
