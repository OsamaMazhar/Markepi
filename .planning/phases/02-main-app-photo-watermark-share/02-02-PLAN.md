    **1. Add pinch-to-resize to PreviewView.swift per D-08 and RESEARCH.md Pattern 4:**

    Add state to `PreviewView`:
    - `@GestureState private var pinchScale: CGFloat = 1.0` — in-flight scale during gesture
    - `@State private var committedScale: CGFloat = 1.0` — final committed scale (gets clamped and sent to engine)

    Compute `var effectiveScale: CGFloat { committedScale * pinchScale }`

    Add `MagnifyGesture()` to the preview `Image`:
    ```swift
    let magnification = MagnifyGesture()
        .updating($pinchScale) { value, state, _ in
            state = value.magnification
        }
        .onEnded { value in
            committedScale *= value.magnification
            let clamped = min(max(committedScale, 0.01), 0.90)
            committedScale = clamped
            viewModel.updateLayerScale(at: viewModel.activeLayerIndex, scale: clamped)
        }
    ```
    Apply `.scaleEffect(effectiveScale)` on the Image view (GPU-accelerated, no CIImage re-render per RESEARCH.md anti-pattern). Only the `.onEnded` updates the engine config scale, which triggers a debounced preview re-render.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| file system → engine | Logo PNG loaded from user's photo library or Files app crosses into WatermarkCore; non-PNG data could cause engine errors |
| gesture input → engine config | MagnifyGesture scale value crosses from view layer to engine configuration; out-of-range values must be clamped |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Denial of Service | LogoPickerView → ImageWatermarkInput | mitigate | Validate `CIImage(data: pngData) != nil` before passing to engine; show "Unsupported Format" alert for non-PNG data. ImageWatermarkInput init validates non-empty data (Phase 1). |
| T-02-06 | Elevation of Privilege | MagnifyGesture | mitigate | Scale value clamped to 0.01–0.90 before passing to engine config (matching Phase 1 validation range); gesture only affects the view transform during flight, engine update only on .onEnded |
| T-02-07 | Information Disclosure | ScaleLabelView overlay | accept | Scale percentage displayed during pinch is derived from watermark config scale × gesture magnification; no sensitive information exposed |
| T-02-08 | Denial of Service | TextEditor input | mitigate | 500-char max enforced in TextWatermarkInputView before config mutation (T-02-01 continuation); rapid text input debounced by .task(id:) auto-cancellation |
