## Spacing Scale

Standard iOS conventions used throughout the phase (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Pill bar inner padding (`MarkepiPillBar` `.padding(4)`) |
| sm | 8pt | Drag indicator top padding (`.padding(.top, 8)`), batch overlay bottom margin |
| md | 12pt | Button vertical padding in `MarkepiButtonStyle` (`.padding(.vertical, 12)`) |
| lg | 16pt | Pill segment horizontal padding (`.padding(.horizontal, 16)`), ControlsView section spacing, ShareActionButton container padding |
| xl | 20pt | Button horizontal padding in `MarkepiButtonStyle` (`.padding(.horizontal, 20)`), sheet top corner radius |
| 2xl | 40pt | Pinned Share bar horizontal padding (`.padding(.horizontal, 40)`) |

Exceptions:
- `peekDetentHeight`: **60pt** — derived from MarkepiPillBar intrinsic height (~44–48pt pill + 8pt drag indicator top + 5pt indicator + 4pt indicator bottom). Planner should measure runtime pill bar height via GeometryReader for Dynamic Type accuracy (A1), falling back to 60pt.
- `expandedDetentRatio`: **0.55** — approximately half screen height following the professional photo-editing convention. Applied as `geometry.size.height * 0.55` (A2).
- Drag indicator size: **36pt width × 5pt height** — standard iOS sheet drag indicator capsule.
- Sheet corner radius: **20pt top** (UnevenRoundedRectangle), **0pt bottom** — standard iOS sheet corners (A4).

## Color

All colors are system-adaptive semantic colors. No hardcoded hex values. Per D-13, both light and dark appearances render correctly without special-casing.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `.clear` / system background | Full-bleed preview area (no background applied — PreviewView fills edge-to-edge). Sheet glass surface auto-adapts to light/dark via `.glassEffect(.regular)` (iOS 26) or `.ultraThinMaterial` (iOS 18). |
| Secondary (30%) | `.regularMaterial` / Liquid Glass | Sheet surface body (`.markepiGlass(shape: UnevenRoundedRectangle, fallbackMaterial: .regularMaterial)`). Glass tint is system-adaptive — cool in light, warm in dark (D-03, D-09). |
| Accent (10%) | `.accentColor` | ShareActionButton when `.buttonStyle(.markepiPrimary())` for `.idle` and `.done` states. System adaptive — cool blue in light mode, warm blue in dark mode. |
| Destructive | `.red` | Batch batch Cancel/Reset All in NavigationStack toolbar — NOT in the sheet or pinned bar. Uses `.markepiDestructive()` button style where applicable (D-10, D-16). |

Accent reserved for: **Primary CTA (Share/Watermark All) only**. No other accent usage in this phase. The sheet surface, drag indicator, pinned bar glass, and all ControlsView controls use `.primary`, `.secondary`, `.selection`, or system materials — never accentColor.

Additional color rules:
- Drag indicator: `.secondary.opacity(0.4)` — subtle hint at draggability (D-10).
- Active pill indicator fill: `.selection` — system-adaptive selection color (set by MarkepiPillBar, not Phase 17).
- Pinned Share bar: Liquid Glass capsule background only — no additional tinting.
- Preview area: **No visual treatment** — no dimming, no blur, no scale as the sheet moves (D-12).

### Empty State
**This phase has no empty state.** The empty state (no photo loaded) is redesigned in Phase 18 (UXQ-04). Phase 17 preserves the existing behavior — PreviewView shows its current empty-state placeholder when no photo is loaded.

### Destructive Actions
No destructive actions are introduced in this phase. Existing destructive actions (batch Cancel, Reset All) remain in the NavigationStack toolbar — NOT in the sheet or pinned bar (D-07, D-16). Batch cancel already has a confirmation dialog (`showBatchCancelConfirmation`) — preserved unchanged.

## Layout & Z-Order Contract

### Z-Stack Layer Map (ContentView)

| zIndex | Layer | Content | Notes |
|--------|-------|---------|-------|
| 0 | Preview | `PreviewView` with `.ignoresSafeArea()` (all edges) | LYT-01: Full-bleed hero. No dimming/blur/scale at any detent (D-12). Background interaction enabled — user can tap/drag the preview image behind the sheet (D-03). |
| 1 | Batch overlays | `ThumbnailStripView` (multi-photo), `BatchProgressOverlay` (batch active) | D-17: Floats between preview and sheet. ThumbnailStrip offsets by `peekDetentHeight + 8pt` to avoid overlap when sheet is at peek. Visible through Liquid Glass. |
| 2 | Inspector sheet | `InspectorSheetView` — drag indicator + `ControlsView` (unchanged) | LYT-02: Resizable detent bottom sheet. Glass surface (D-09). Standard drag indicator (D-10). Rounded top corners, square bottom (D-11). Not dismissible (D-04). |
| 3 | Pinned Share bar | `ShareActionButton` in Liquid Glass pill | LYT-03: Always visible and reachable, regardless of sheet detent. Floats independently from the sheet. Positioned at `peekDetentHeight + 16pt` from bottom. |

### Detent States

| Detent | Height | What's Visible |
|--------|--------|----------------|
| `.peek` | ~60pt (pill bar + drag indicator) | Drag indicator + pill bar labels (Watermark/Style/Output). No control content. Default detent. |
| `.expanded` | ~55% screen height | Drag indicator + full ControlsView with all controls. User drags up to expand, down to peek. |

### Sheet Interaction Contract

| Property | Behavior |
|----------|----------|
| Dismissibility | **Not dismissible** — always shows at least peek. Cannot be dragged off-screen (D-04). |
| Drag-to-resize | Drag gesture on indicator capsule ONLY (avoids conflict with ControlsView scroll — D-15). Upward drag expands, downward drag collapses. |
| Detent snap threshold | **50pt** drag distance from current detent to switch (standard iOS convention). Variable per A2/Open Question 2: threshold = `min(50, (expandedHeight - peekHeight) * 0.3)`. |
| Snap animation | `.spring(response: 0.4, dampingFraction: 0.85)` — matches native iOS sheet spring feel. |
| Nested scroll | Architectural separation: DragGesture on indicator only; ControlsView ScrollView receives all content-scroll gestures unimpeded (D-15). |
| Background interaction | Enabled — user can interact with the preview area behind the sheet (tap/pinch/pan photo) even with sheet visible (D-03). |
| Preview treatment | **None** — no dimming, no blur, no scale applied to preview as sheet expands/collapses (D-12). |

### Pinned Action Bar Contract

| Property | Behavior |
|----------|----------|
| Content | ShareActionButton only — no batch controls, no import button (D-07). |
| Positioning | Floating pill centered horizontally at bottom of preview area. Base offset: `peekDetentHeight + 16pt` from screen bottom. Always above sheet (zIndex 3 > 2). |
| Styling | Liquid Glass `Capsule()` background (D-06). 52pt height, 24pt horizontal inset for glass background. ShareActionButton padded at 40pt horizontal. |
| Visibility | Always visible — independent of sheet detent (D-06). |

### NavigationStack Toolbar (Unchanged)

| Item | Location | Notes |
|------|----------|-------|
| Cancel (batch) | Leading toolbar | Existing behavior, preserved (D-16). |
| Reset All (batch) | Trailing toolbar | Existing behavior, preserved (D-16). |
| Import button | Top-right of preview area (custom, not toolbar) | Existing plus-button overlay — preserved in preview ZStack. |

## Interaction States

### Sheet Detent Transitions

| From | To | Trigger | Animation |
|------|----|---------|-----------|
| `.peek` | `.expanded` | User drags indicator up > 50pt threshold | `.spring(response: 0.4, dampingFraction: 0.85)` |
| `.expanded` | `.peek` | User drags indicator down > 50pt threshold | `.spring(response: 0.4, dampingFraction: 0.85)` |
| Any | `.peek` | Default on first load (no photo loaded or photo loaded) | No animation — starts at peek |

During drag: sheet height tracks finger with `dragOffset` (no animation). Snap animation fires in `onEnded` only. `dragOffset` resets to 0 after snap completes.

### ShareActionButton State Machine

| State | Visual | Behavior |
|-------|--------|----------|
| `.idle` | `Label("Share", "square.and.arrow.up")` or `Label("Watermark All", "square.and.arrow.up.on.square.fill")`. `.buttonStyle(.markepiPrimary())`. | Tap → `viewModel.renderAndPrepareShare()` |
| `.rendering` | ProgressView + "Rendering..." label in glass capsule. Disabled. | No user interaction |
| `.renderingVideo(progress, eta)` | Progress bar (progress × width) + "X% — Y remaining" + Cancel button | Cancel → `viewModel.cancelProcessing()` |
| `.batchProcessing(current, total, eta)` | Progress bar + "Processing X of Y (Z remaining)" + Stop button (`.buttonStyle(.markepiSecondary())`) | Stop → cancel confirmation (existing) |
| `.done` | `Label("Ready to Share", "checkmark.circle.fill")` or `Label("Ready to Share All", ...)`. `.buttonStyle(.markepiPrimary())`. | Tap → `viewModel.presentShareSheet()` |
| `.error` | `Label("Retry", "arrow.clockwise")`. `.buttonStyle(.markepiSecondary())`. | Tap → `viewModel.renderAndPrepareShare()` |

Transitions between states animate with `.easeInOut(duration: 0.2)` unless Reduce Motion is active (UXQ-03 — Phase 18, but wired here: `animation(reduceMotion ? nil : .easeInOut)`).

### Accessibility Interactions

| Interaction | Behavior |
|-------------|----------|
| Drag indicator VoiceOver | "Resize controls" label. "Drag up to show all controls, down to minimize" hint (UXQ-02). Swipe up/down to resize. |
| Pinned Share button | Standard VoiceOver button announcement — label reflects current rendering state. |
| Sheet glass + Reduce Transparency | `markepiGlass(isEnabled: !reduceTransparency)` — when Reduce Transparency is ON, glass is disabled entirely, rendering solid surfaces (UXQ-03). |
| Spring animations + Reduce Motion | `animation(reduceMotion ? nil : .spring(...))` — snap animation is linear/fades when Reduce Motion is ON. |
