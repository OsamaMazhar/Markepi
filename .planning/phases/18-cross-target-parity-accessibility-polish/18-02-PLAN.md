## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| VoiceOver → Pill Bar Labels | Accessibility labels expose UI function names — descriptive but not internal-state-revealing |
| VoiceOver → ControlSection Labels | Container labels identify content group — no internal data exposed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-04 | Information Disclosure | VoiceOver labels | mitigate | Labels use descriptive functional text per D-13 ("Watermark controls", "Style controls", "Output controls") — describe what the control does, not internal state or implementation details. No config data, file paths, or user data exposed through labels. |
| T-18-05 | Denial of Service | Reduce Motion gating | accept | Reduce Motion gating is a UI quality concern, not a security boundary. The worst case without gating is a jarring animation — no crash, data loss, or resource exhaustion risk. |
| T-18-06 | Information Disclosure | ControlSection label strings | accept | Container labels like "Text and position controls" and "Export options" are function-descriptive, not data-bearing. No user config, watermark text, or file metadata exposed. |
</threat_model>
