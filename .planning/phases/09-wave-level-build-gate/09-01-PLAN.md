<objective>
Deliver a wave-level build gate: two bash scripts (`build-gate.sh`, `test-build-gate.sh`) and an AGENTS.md documentation update. The gate runs `xcodebuild` across all 3 targets (WatermarkApp, ShareExtension, PhotoEditExtension) via the single WatermarkApp scheme after each execution wave, replacing file-existence-only self-checks as the source of truth for build pass/fail.

or self-checks claimed "PASSED" without actual `xcodebuild` invocation.

</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer → scripts/build-gate.sh | Shell invocation with zero arguments (no injection surface) |
| scripts/test-build-gate.sh → App/Intents/WatermarkAppShortcuts.swift | Fixture test mutates a source file in-place; must restore on both pass and failure paths |
| scripts/test-build-gate.sh → git | Uses `git checkout` for atomic file restoration; trap with `|| true` prevents cleanup errors from masking test results |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | scripts/build-gate.sh | mitigate | Script accepts zero arguments — no injection surface. `set -u` catches any unset variable references. The only command invoked is `xcodebuild` with hardcoded, static arguments. |
| T-09-02 | Tampering | scripts/test-build-gate.sh (file restoration) | mitigate | `trap 'git -C "$REPO_ROOT" checkout -- "$TEST_FILE" 2>/dev/null \|\| true' EXIT` ensures the source file is restored on both normal exit and early failure (errexit). The `\|\| true` prevents cleanup errors from masking test assertion failures (RESEARCH.md Pitfall 3). |
| T-09-03 | Information Disclosure | xcodebuild stdout/stderr | accept | xcodebuild outputs build settings, compiler messages, and file paths — no secrets, no PII, no tokens. Output flows to the same terminal the gsd-executor already uses. Risk is identical to running xcodebuild directly, which developers already do. |
| T-09-04 | Denial of Service | scripts/test-build-gate.sh (concurrent mutation) | accept | The test mutates `App/Intents/WatermarkAppShortcuts.swift` in-place. Waves are sequential — no concurrent execution. If another process modifies the same file simultaneously (extremely unlikely), `git checkout` would fail to restore cleanly, but `\|\| true` ensures the test still reports its own result. A failed restoration is obvious (file shows as modified in git status). |
| T-09-SC | Tampering | npm/pip/cargo installs | not applicable | This phase installs zero external packages. All tools (bash, xcodebuild, git) are pre-installed system binaries on macOS. No package legitimacy audit needed (RESEARCH.md confirms this). |
</threat_model>
