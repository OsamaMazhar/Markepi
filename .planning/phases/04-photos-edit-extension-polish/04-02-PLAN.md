## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| audiovisualAsset → ViewModel | AVAsset from Photos library crosses into app code; cast to AVURLAsset to extract URL, handle nil gracefully |
| Video output → renderedContentURL | Engine-processed video written to system URL; validate write succeeds, handle Data.write errors |
| Full config → AppGroupConfigSync | Image watermark PNG data stored in shared UserDefaults for rehydration; already validated by existing AppGroupConfigSync pattern |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Denial of Service | Video processing in extension sandbox | mitigate | Use engine.processVideo() which streams via AVAssetExportSession — never loads full video into memory; guard sourceURL validity before processing; cancelContentEditing on unrecoverable errors |
| T-04-07 | Information Disclosure | Image watermark PNG in App Group UserDefaults | accept | App Group restricted to own targets; PNG data stored for rehydration is same data user already provided; no PII in watermark images |
| T-04-08 | Tampering | rehydrateImageData() matching by position/scale | mitigate | Match .image layers by position AND scale (both must match); if no match found, keep placeholder — don't silently hydrate wrong image; validate rehydrated pngData is non-empty before use |
| T-04-09 | Denial of Service | PHAdjustmentData with large image config | mitigate | strippingImageData() ensures encoded JSON < 1 MB (replaces pngData with 68-byte placeholder); validate encoded data size before creating PHAdjustmentData |
</threat_model>
