## Engineering Notes (read before coding)

**Test command (same constraint — `swift test` is broken here):**
```bash
cd Packages/WatermarkCore
xcodebuild test -scheme WatermarkCore \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -only-testing:WatermarkCoreTests/ProvenanceControlsTests
```

**Two different lifetimes — keep them separate:**
- **Persisted, user-editable** (rights, privacy profile, C2PA toggle, signing preference, source declaration, invisible toggle) → store in `WatermarkConfiguration` so `AppGroupConfigSync` carries them to the Share Extension automatically. Reachable in views via `$viewModel.config.…` because the protocol exposes `var config: WatermarkConfiguration { get set }` and views use `@Bindable`.
- **Runtime, per-photo** (the `SourceProvenanceReport` from the analyzer, and the post-export `ExportReceipt`) → these are NOT persisted. Add them as a new read-only protocol member on `WatermarkConfigurable` and implement in BOTH `WatermarkViewModel` and `ShareExtensionViewModel`.

**Backward-compatible decoding is mandatory (acceptance criterion).** `WatermarkConfiguration` already hand-rolls `init(from:)`/`encode(to:)` with `decodeIfPresent ?? default`. Add every new key the SAME way. Existing template/config JSON has none of these keys, so each must decode to a safe default — and the default must NOT enable verified-camera language (it can't: that's gated by the runtime report, not config).

**Generic view pattern:** follow `ScaleStepperView` / `ControlsView` exactly — `struct ProvenanceControlsView<ViewModel: WatermarkConfigurable & Observable>: View` with `@Bindable var viewModel`. This is what lets the app and Share Extension share one view.

**Protocol additions ripple to two ViewModels.** `WatermarkConfigurable` is consumed by `WatermarkViewModel` (App) and `ShareExtensionViewModel`. Any new requirement you add must be implemented in both or the build gate fails. Prefer a protocol-extension default where possible (e.g. `sourceProvenanceReport` default `nil`).
</engineering_notes>

```swift
// New stored properties (use the types created in 19-01 / 19-02):
public var rightsMetadata: RightsMetadata = RightsMetadata()
public var metadataPrivacyProfile: MetadataPrivacyProfile = .preserveAll
public var includeC2PAManifest: Bool = false
public var sourceDeclaration: UserSourceDeclaration = .none
public var invisibleProtectionEnabled: Bool = false

// Extend the EXISTING CodingKeys enum:
enum CodingKeys: String, CodingKey {
    case watermarks, padding, whiteFrame, dateStamp, outputFormat, outputQuality
    case rightsMetadata, metadataPrivacyProfile, includeC2PAManifest
    case sourceDeclaration, invisibleProtectionEnabled
}

// In init(from:) — every new key is decodeIfPresent ?? default (migration-safe):
self.rightsMetadata = try container.decodeIfPresent(RightsMetadata.self, forKey: .rightsMetadata) ?? RightsMetadata()
self.metadataPrivacyProfile = try container.decodeIfPresent(MetadataPrivacyProfile.self, forKey: .metadataPrivacyProfile) ?? .preserveAll
self.includeC2PAManifest = try container.decodeIfPresent(Bool.self, forKey: .includeC2PAManifest) ?? false
self.sourceDeclaration = try container.decodeIfPresent(UserSourceDeclaration.self, forKey: .sourceDeclaration) ?? .none
self.invisibleProtectionEnabled = try container.decodeIfPresent(Bool.self, forKey: .invisibleProtectionEnabled) ?? false

// In encode(to:) — encode each new key.
```

### `ProvenanceControlsView.swift` (Tasks 2 + 3)

```swift
import SwiftUI

/// Provenance + rights + privacy controls, shared by app and Share Extension.
/// Generic over the same ViewModel protocol ControlsView uses.
public struct ProvenanceControlsView<ViewModel: WatermarkConfigurable & Observable>: View {
    @Bindable var viewModel: ViewModel
    public init(viewModel: ViewModel) { self.viewModel = viewModel }

    private var report: SourceProvenanceReport? { viewModel.sourceProvenanceReport }

    public var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            // 1. Source-state badge — neutral, gated wording (CTRL-02/03).
            HStack(spacing: 6) {
                Image(systemName: badgeIcon)
                Text(report?.state.displayLabel ?? "Analyzing source…")
                    .markepiTypography(.controlLabel)
            }

            // 2. Evidence summary (collapsible row is fine).
            if let evidence = report?.evidence, !evidence.isEmpty {
                ForEach(evidence) { e in
                    Text("\(e.source): \(e.summary)")
                        .markepiTypography(.value)
                        .foregroundStyle(.secondary)
                }
            }

            // 3. Rights editor — bound through persisted config.
            TextField("Creator", text: $viewModel.config.rightsMetadata.creator)
            TextField("Copyright", text: $viewModel.config.rightsMetadata.copyrightNotice)
            TextField("Credit", text: $viewModel.config.rightsMetadata.creditLine)

            // 4. Metadata privacy (CTRL-04).
            Picker("Metadata privacy", selection: $viewModel.config.metadataPrivacyProfile) {
                Text("Keep all").tag(MetadataPrivacyProfile.preserveAll)
                Text("Remove location & device IDs").tag(MetadataPrivacyProfile.stripSensitive)
                Text("Minimal").tag(MetadataPrivacyProfile.minimalPublic)
            }

            // 5. C2PA Content Credentials (Markepi wording — D-23).
            Toggle("Add Content Credentials (C2PA)", isOn: $viewModel.config.includeC2PAManifest)

            // 6. Source declaration — clearly a DECLARATION, never "verified" (D-18).
            Picker("Declare source", selection: $viewModel.config.sourceDeclaration) {
                Text("Don’t declare").tag(UserSourceDeclaration.none)
                Text("I declare: Camera").tag(UserSourceDeclaration.camera)
                Text("I declare: AI").tag(UserSourceDeclaration.ai)
                Text("I declare: AI-edited").tag(UserSourceDeclaration.aiEdited)
            }

            // 7. GATE: verified-camera affordance only when evidence supports it
            //    (D-17). There is intentionally NO "No AI Used" control (D-05).
            if report?.allowsVerifiedCameraClaim == true {
                Label("Verified camera capture", systemImage: "checkmark.seal.fill")
                    .foregroundStyle(.green)
            }

            // 8. Invisible protection — disabled placeholder until 19-04 ships a provider.
            Toggle("Invisible creator protection (coming soon)",
                   isOn: $viewModel.config.invisibleProtectionEnabled)
                .disabled(true)
        }
        .padding(16)
    }

    private var badgeIcon: String {
        switch report?.state {
        case .verifiedCameraCapture: return "checkmark.seal"
        case .markedAI:              return "sparkles"
        case .userDeclared:          return "person.crop.circle.badge.questionmark"
        case .suspectedAI:           return "questionmark.diamond"
        case .unknown, .none:        return "questionmark.circle"
        }
    }
}
```

```swift
import SwiftUI

/// Receipt shown after export preparation, before/around the share action.
/// Works in both app and Share Extension flows; offline-only.
public struct ExportReceiptView: View {
    public let receipt: ExportReceipt
    public init(receipt: ExportReceipt) { self.receipt = receipt }

    public var body: some View {
        List {
            Section("Source") {
                LabeledContent("State", value: receipt.report.state.displayLabel)
                ForEach(receipt.report.evidence) { e in
                    LabeledContent(e.source, value: e.summary)
                }
                if receipt.report.userDeclaration != .none {
                    LabeledContent("Declared by user",
                                   value: receipt.report.userDeclaration.rawValue)   // D-19
                }
            }
            Section("Records added") {
                LabeledContent("Content Credentials", value: signingText)
                if receipt.signingResult?.status == .signed, let s = receipt.signingResult {
                    Text("Signed with \(s.displayName). This is a device signing identity, "
                         + "not a verified legal identity.")                         // D-24
                        .font(.footnote).foregroundStyle(.secondary)
                }
            }
            if !(receipt.signingResult?.warnings.isEmpty ?? true) {
                Section("Notes") {
                    ForEach(receipt.signingResult?.warnings ?? [], id: \.self) { Text($0) }
                }
            }
        }
    }

    private var signingText: String {
        switch receipt.signingResult?.status {
        case .signed:       return "Signed"
        case .notSigned:    return "Not signed"
        case .notSupported: return "Not supported for this format"
        case .none:         return "Not signed"
        }
    }
}
```

Lightweight, pixel-free metadata read — add to `SourceProvenanceAnalyzer` (19-01) so the trigger doesn't decode the whole image or choke on videos:
```swift
extension SourceProvenanceAnalyzer {
    /// Convenience: reads ImageIO properties WITHOUT decoding pixels and analyzes.
    /// Returns nil for non-image URLs (e.g. video) — caller supplies a fallback.
    public func analyze(imageURL: URL,
                        userDeclaration: UserSourceDeclaration = .none,
                        c2paSummary: C2PASummary? = nil) -> SourceProvenanceReport? {
        guard let src = CGImageSourceCreateWithURL(imageURL as CFURL, nil),
              let props = CGImageSourceCopyPropertiesAtIndex(src, 0, nil) as? [CFString: Any]
        else { return nil }
        var metadata: [String: Any] = [:]
        for (k, v) in props { metadata[k as String] = v }
        return analyze(metadata: metadata, userDeclaration: userDeclaration, c2paSummary: c2paSummary)
    }
}
```
