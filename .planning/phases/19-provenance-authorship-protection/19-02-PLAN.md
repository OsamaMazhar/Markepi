## Engineering Notes (read before coding)

**Test command (same constraint as 19-01 — `swift test` is broken here):**
```bash
cd Packages/WatermarkCore
xcodebuild test -scheme WatermarkCore \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -only-testing:WatermarkCoreTests/ProvenanceExportTests
```

**Where the export pipeline actually hooks (verified against `WatermarkEngine.process`):**
- Source metadata is extracted once by `ImageLoader.load(from:)` → `loaded.metadata` (`[String: Any]`).
- The watermark is composited, rendered to a `CGImage`, then written by `ImageWriter.write(cgImage:metadata:gainMapAuxData:dngMetadata:destinationUTI:quality:to:)`.
- **IPTC rights + privacy stripping happen on the `[String: Any]` dict BEFORE `ImageWriter.write`** — merge into the `metadata` argument. `ImageWriter` already calls `resetOrientation` and re-attaches the HDR gain map, so do not touch pixels or gain map.
- **C2PA signing happens AFTER `ImageWriter.write`** — c2pa-swift attaches a manifest to the already-written file at `outputURL` (stream/file API). Add the source as an *ingredient* so existing provenance survives (D-04, AUTH-04).

**Additive API only — don't break existing callers.** `process(...)` is called from several places. Add a `provenance: ProvenanceExportOptions? = nil` parameter (nil ⇒ exactly today's behavior, no receipt). Add an optional `provenanceReceipt: ExportReceipt? = nil` to `ProcessingResult` (give it a default so existing initializer call sites keep compiling).

**Package integration reality (Task 1 risk):** the build gate (`scripts/build-gate.sh`) builds the **Xcode project** scheme `WatermarkApp` for `generic/platform=iOS`, not `swift build`. Adding c2pa-swift to `Packages/WatermarkCore/Package.swift` means the app and Share Extension targets must transitively resolve it through the local WatermarkCore package. After adding the dependency, the gate must still pass for BOTH targets. If c2pa-swift ships as a large binary/XCFramework or fails to resolve in the project, take the documented Fallback: keep the `C2PAProvenanceClient` protocol + `NoopC2PAProvenanceClient`, guard the concrete client with `#if canImport(C2PA)`, and record the blocker in the summary. Do NOT hand-roll C2PA serialization.

**c2pa-swift signing needs a certificate, not just a key.** Secure Enclave / Keychain gives you the private key; C2PA signing also needs a signing certificate (self-signed is acceptable for a device identity in v2.2). Treat cert generation as part of the Task 1 integration spike; the `C2PASigningIdentity` below carries the `SecKey`, and the concrete client supplies/ò generates the matching cert.

**Video (Task 6):** C2PA/IPTC for video containers is format-limited. If the chosen c2pa-swift path can't sign the video, set a receipt warning ("Video Content Credentials not available for this format") rather than reporting success (acceptance criterion).

**Sealed author is compulsory (D-26 / Tier 1).** Signing is only triggered with a non-empty `RightsMetadata.creator` (enforced by 19-03's UI). The manifest builder MUST emit the creator as a `stds.schema-org.CreativeWork` author assertion (sealed, tamper-evident), not only as the IPTC byline. Add `creator` to `C2PAManifestRequest` and include it in the manifest JSON. Keep wording Tier-1 honest ("stated by owner / sealed", never "verified identity"). See 19-RESEARCH "Identity Assurance Tiers" for Tier 1/2/3 and why Tier 2 (CA-issued cert) and Tier 3 (CAWG identity assertion) are out of v2.2 scope.
</engineering_notes>

### `C2PASigningIdentityStore.swift` (Task 2)

```swift
import Foundation
import Security

/// A LOCAL device signing identity. NOT a verified legal/person identity (D-24).
public struct C2PASigningIdentity: Sendable {
    public enum IdentityType: String, Codable, Sendable { case secureEnclave, localSoftware, unsupported }
    public let type: IdentityType
    /// Receipt-safe wording mandated by D-24.
    public var displayName: String { "Markepi device signing identity" }
    /// Private key handle; Secure Enclave keys are non-exportable by construction.
    public let secKey: SecKey?
}

/// Creates/loads a signing key: Secure Enclave first, local Keychain software
/// fallback only when SE is unavailable (simulator/dev) — D-24. No network.
public struct C2PASigningIdentityStore {
    private static let tag = "com.osamamazhar.markepi.c2pa.signing".data(using: .utf8)!
    public init() {}

    public func currentIdentity() -> C2PASigningIdentity {
        if let key = makeKey(secureEnclave: true) {
            return C2PASigningIdentity(type: .secureEnclave, secKey: key)
        }
        if let key = makeKey(secureEnclave: false) {
            return C2PASigningIdentity(type: .localSoftware, secKey: key)
        }
        return C2PASigningIdentity(type: .unsupported, secKey: nil)
    }

    private func makeKey(secureEnclave: Bool) -> SecKey? {
        var attrs: [String: Any] = [
            kSecAttrKeyType as String: kSecAttrKeyTypeECSECPrimeRandom,
            kSecAttrKeySizeInBits as String: 256,
            kSecPrivateKeyAttrs as String: [
                kSecAttrIsPermanent as String: true,
                kSecAttrApplicationTag as String: Self.tag,
            ],
        ]
        if secureEnclave { attrs[kSecAttrTokenID as String] = kSecAttrTokenIDSecureEnclave }
        var error: Unmanaged<CFError>?
        // On Simulator, SE creation returns nil → caller falls back to software.
        return SecKeyCreateRandomKey(attrs as CFDictionary, &error)
    }
}
```

### `C2PAProvenanceClient.swift` (Task 3)

```swift
import Foundation

/// Adapter boundary over C2PA read/verify/sign so the engine never depends on a
/// concrete library (D-11/D-12). Async + Sendable ⇒ Share-Extension safe.
public protocol C2PAProvenanceClient: Sendable {
    /// Read & verify any manifest already in the source; returns the small
    /// summary the 19-01 analyzer consumes. nil = no manifest.
    func readSourceSummary(from url: URL) async -> SourceProvenanceAnalyzer.C2PASummary?

    /// Build + sign a Markepi manifest and attach it to `outputURL` in place.
    /// `source` becomes an ingredient so existing provenance is preserved (D-04).
    func signExport(outputURL: URL, source: URL,
                    manifest: C2PAManifestRequest,
                    identity: C2PASigningIdentity) async throws -> C2PASigningResult
}

/// Everything Markepi asserts, honestly (D-06, AUTH-02). User declaration is
/// represented separately from any verified claim.
public struct C2PAManifestRequest: Sendable {
    public var appName = "Markepi"                    // D-23
    public var appVersion: String
    public var exportedAt = Date()
    public var sourceState: ProvenanceState
    public var sourceEvidenceSummary: [String]
    public var visibleWatermarkApplied: Bool
    public var whiteFrameApplied: Bool
    public var privacyAction: String?                 // e.g. "GPS removed"
    public var userDeclaration: UserSourceDeclaration // recorded as declaration
    public var invisibleWatermarkPayloadID: String?   // optional soft-binding id
    public init(appVersion: String, sourceState: ProvenanceState,
                sourceEvidenceSummary: [String], visibleWatermarkApplied: Bool,
                whiteFrameApplied: Bool, privacyAction: String?,
                userDeclaration: UserSourceDeclaration, invisibleWatermarkPayloadID: String?) {
        self.appVersion = appVersion; self.sourceState = sourceState
        self.sourceEvidenceSummary = sourceEvidenceSummary
        self.visibleWatermarkApplied = visibleWatermarkApplied
        self.whiteFrameApplied = whiteFrameApplied; self.privacyAction = privacyAction
        self.userDeclaration = userDeclaration; self.invisibleWatermarkPayloadID = invisibleWatermarkPayloadID
    }
}

public struct C2PASigningResult: Sendable, Codable, Equatable {
    public enum Status: String, Sendable, Codable { case signed, notSigned, notSupported }
    public let status: Status
    public let identityType: C2PASigningIdentity.IdentityType
    public let displayName: String           // "Markepi device signing identity"
    public let warnings: [String]
    public init(status: Status, identityType: C2PASigningIdentity.IdentityType,
                displayName: String, warnings: [String] = []) {
        self.status = status; self.identityType = identityType
        self.displayName = displayName; self.warnings = warnings
    }
}

/// Safe default when c2pa-swift is unavailable/disabled. Always reports
/// notSigned so the receipt stays honest.
public struct NoopC2PAProvenanceClient: C2PAProvenanceClient {
    public init() {}
    public func readSourceSummary(from url: URL) async -> SourceProvenanceAnalyzer.C2PASummary? { nil }
    public func signExport(outputURL: URL, source: URL, manifest: C2PAManifestRequest,
                           identity: C2PASigningIdentity) async throws -> C2PASigningResult {
        C2PASigningResult(status: .notSigned, identityType: identity.type,
                          displayName: identity.displayName,
                          warnings: ["C2PA signing is disabled in this build."])
    }
}
```

### `RightsMetadata.swift` + `IPTCRightsMetadataWriter.swift` (Task 4)

```swift
import ImageIO
import Foundation

public struct RightsMetadata: Codable, Equatable, Sendable {
    public var creator: String = ""
    public var copyrightNotice: String = ""
    public var creditLine: String = ""
    public var usageTerms: String = ""
    public var licensorURL: String = ""
    /// IPTC controlled-vocabulary URI; nil = leave any source value untouched.
    public var digitalSourceType: String?
    public init() {}
}

/// Merges rights fields into an ImageIO metadata dict WITHOUT dropping unrelated
/// EXIF/XMP (AUTH-03, D-07). Pure function — returns a new dict.
public struct IPTCRightsMetadataWriter {
    public init() {}
    public func merged(into metadata: [String: Any], rights: RightsMetadata) -> [String: Any] {
        var out = metadata
        var iptc = out[kCGImagePropertyIPTCDictionary as String] as? [String: Any] ?? [:]
        if !rights.creator.isEmpty { iptc[kCGImagePropertyIPTCByline as String] = [rights.creator] }
        if !rights.copyrightNotice.isEmpty { iptc[kCGImagePropertyIPTCCopyrightNotice as String] = rights.copyrightNotice }
        if !rights.creditLine.isEmpty { iptc[kCGImagePropertyIPTCCredit as String] = rights.creditLine }
        if !rights.usageTerms.isEmpty { iptc[kCGImagePropertyIPTCRightsUsageTerms as String] = rights.usageTerms }
        if let dst = rights.digitalSourceType { iptc[kCGImagePropertyIPTCExtDigitalSourceType as String] = dst }
        out[kCGImagePropertyIPTCDictionary as String] = iptc

        // Copyright also in TIFF for broad reader compatibility.
        if !rights.copyrightNotice.isEmpty {
            var tiff = out[kCGImagePropertyTIFFDictionary as String] as? [String: Any] ?? [:]
            tiff[kCGImagePropertyTIFFCopyright as String] = rights.copyrightNotice
            out[kCGImagePropertyTIFFDictionary as String] = tiff
        }
        return out
    }
}
```

### `MetadataPreservationPolicy.swift` (Task 5)

```swift
import ImageIO
import Foundation

public enum MetadataPrivacyProfile: String, Codable, Sendable {
    case preserveAll, stripSensitive, minimalPublic
}

/// Applies a privacy profile to an ImageIO metadata dict. Rights/provenance
/// (IPTC, copyright) survive `stripSensitive`; HDR gain map + color profile are
/// untouched because they are re-attached by ImageWriter, not carried here.
public struct MetadataPreservationPolicy {
    public init() {}
    public func apply(_ profile: MetadataPrivacyProfile, to metadata: [String: Any]) -> [String: Any] {
        switch profile {
        case .preserveAll:
            return metadata
        case .stripSensitive:
            var out = metadata
            out.removeValue(forKey: kCGImagePropertyGPSDictionary as String)        // CTRL-04
            if var exif = out[kCGImagePropertyExifDictionary as String] as? [String: Any] {
                exif.removeValue(forKey: kCGImagePropertyExifBodySerialNumber as String)
                exif.removeValue(forKey: kCGImagePropertyExifLensSerialNumber as String)
                out[kCGImagePropertyExifDictionary as String] = exif
            }
            out.removeValue(forKey: kCGImagePropertyMakerAppleDictionary as String)  // device-specific maker note
            return out
        case .minimalPublic:
            var out: [String: Any] = [:]
            for key in [kCGImagePropertyIPTCDictionary, kCGImagePropertyPixelWidth,
                        kCGImagePropertyPixelHeight, kCGImagePropertyProfileName] {
                if let v = metadata[key as String] { out[key as String] = v }
            }
            return out
        }
    }
}
```

### Export hook (Task 6) — additive wiring inside `WatermarkEngine.process`

```swift
/// Options the caller passes to opt INTO provenance work. nil ⇒ today's behavior.
public struct ProvenanceExportOptions: Sendable {
    public var rights: RightsMetadata
    public var privacyProfile: MetadataPrivacyProfile
    public var includeC2PA: Bool
    public var userDeclaration: UserSourceDeclaration
    public var appVersion: String
    public var c2paClient: any C2PAProvenanceClient   // inject Noop or concrete
    // … plus visibleWatermarkApplied / whiteFrameApplied are derived from config.
}

// Signature gains one optional parameter (keeps every existing call site valid):
public func process(
    sourceURL: URL,
    config: WatermarkConfiguration,
    metadataOverride: [String: Any]? = nil,
    provenance: ProvenanceExportOptions? = nil
) async throws -> ProcessingResult {
    let loaded = try ImageLoader.load(from: sourceURL)
    // … existing normalize / buildFilterGraph / createCGImage unchanged …

    // Metadata we will hand to ImageWriter (default = today's loaded.metadata).
    var outgoing = loaded.metadata
    var report: SourceProvenanceReport?

    if let p = provenance {
        let c2paSummary = await p.c2paClient.readSourceSummary(from: sourceURL)   // (a) analyze
        report = SourceProvenanceAnalyzer().analyze(
            metadata: loaded.metadata, userDeclaration: p.userDeclaration, c2paSummary: c2paSummary)
        outgoing = MetadataPreservationPolicy().apply(p.privacyProfile, to: outgoing) // (c) privacy
        outgoing = IPTCRightsMetadataWriter().merged(into: outgoing, rights: p.rights) // (d) IPTC
    }

    let destinationUTI = config.outputFormat.uti ?? loaded.sourceUTI
    let outputURL = try TempFileManager.createTempFile(uti: destinationUTI as CFString)
    try ImageWriter.write(cgImage: cgImage, metadata: outgoing,
                          gainMapAuxData: loaded.gainMapAuxData, dngMetadata: loaded.dngMetadata,
                          destinationUTI: destinationUTI, quality: config.outputQuality, to: outputURL)

    var receipt: ExportReceipt? = report.map { ExportReceipt(report: $0) }
    if let p = provenance, p.includeC2PA {                                          // (e) sign AFTER write
        let identity = C2PASigningIdentityStore().currentIdentity()
        let manifest = C2PAManifestRequest(
            appVersion: p.appVersion, sourceState: report?.state ?? .unknown,
            sourceEvidenceSummary: report?.evidence.map(\.summary) ?? [],
            visibleWatermarkApplied: !config.watermarks.isEmpty,
            whiteFrameApplied: config.whiteFrame?.isEnabled == true,
            privacyAction: p.privacyProfile == .preserveAll ? nil : "Sensitive metadata removed",
            userDeclaration: p.userDeclaration, invisibleWatermarkPayloadID: nil)
        let signing = try await p.c2paClient.signExport(
            outputURL: outputURL, source: sourceURL, manifest: manifest, identity: identity)
        receipt?.signingResult = signing
    }

    return ProcessingResult(url: outputURL, data: nil, outputUTI: destinationUTI,
                            provenanceReceipt: receipt)
}
```
