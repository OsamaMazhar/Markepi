</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Denial of Service | `CGImageSourceCreateWithURL` on crafted image | accept | Apple's ImageIO parser is hardened against malformed files — returns nil gracefully. No crash or hang surface. This is read-only metadata inspection, not a processing pipeline. |
| T-11-02 | Elevation of Privilege | `fullSizeImageURL` outside sandbox | accept | iOS sandbox prevents access to URLs outside the extension's container. `CGImageSourceCreateWithURL` will fail gracefully (return nil) for inaccessible files. |
| T-11-03 | Information Disclosure | `AVAssetTrack.hasMediaCharacteristic` on crafted format descriptions | accept | Reads metadata only — no pixel data access. AVFoundation's format description parser handles malformed data by returning false for characteristic checks. No PII involved. |
| T-11-04 | Elevation of Privilege | Code injection via UTI string | accept | UTI strings from `CGImageSourceGetType` are system-generated. String comparison (`== "public.heic"`) has no injection surface. No string evaluation, no format string usage. |
| T-11-SC | Tampering | npm/pip/cargo installs | accept | No external packages installed in this phase. All dependencies are Apple system frameworks bundled with iOS 18 SDK. |

**Security assessment:** No mitigations needed. All detection APIs are read-only metadata inspections operating on system-provided inputs within the iOS sandbox. No user-controlled data is parsed or evaluated. No new trust boundaries are introduced — the detection code runs at the same privilege level as the existing `startEditing` method.
