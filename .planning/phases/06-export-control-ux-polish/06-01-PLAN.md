<objective>
Add export format selection (HEIC, JPEG, PNG, TIFF) and quality control (60–100% slider) to the watermark pipeline. The OutputFormat enum gains a `.tiff` case, WatermarkConfiguration gains an `outputQuality` Float property, ImageWriter accepts a destination UTI + quality value, and the engine resolves format from config before writing. Export Options appear as a DisclosureGroup in ControlsView between watermark controls and the share button. HDR→JPEG lossy conversion triggers an advisory confirmation dialog.

Purpose: Users can control output format and compression quality before sharing, per EXPT-01/02/03. All format/quality choices flow through the existing pipeline preserving HDR and metadata where the target format allows.

Output: Engine-level format override support, quality slider UI, TIFF format support, and HDR loss warning dialog.
</objective>
