<objective>
Add before/after comparison via long-press gesture in the preview area. Press and hold toggles the preview from watermarked to the original source image; release returns to watermarked. Includes an "Original" label overlay with fade animation and light impact haptic feedback. Works for both photos (cached original UIImage) and videos (cached static frame via VideoFrameExtractor). The long-press coexists with the existing pinch-to-scale MagnifyGesture using `.simultaneously(with:)`.

Purpose: Users can verify their watermark configuration by comparing against the original, per COMP-01/02. Matches iOS "peek" interaction pattern with no gesture conflict with existing swipe navigation or pinch zoom.

Output: Long-press comparison toggle in PreviewView, source image caching in both ViewModels, video frame extraction for comparison.
</objective>

       - `@State private var hapticTrigger: Bool = false` — triggers `.sensoryFeedback` on state change

    2. Build the comparison long-press gesture (per D-06: minimumDuration 0.15):
       ```swift
       private var comparisonGesture: some Gesture {
           LongPressGesture(minimumDuration: 0.15)
               .updating($isComparing) { value, state, transaction in
                   let wasComparing = state
                   state = value
                   // Trigger haptic on state transition (false→true or true→false)
                   if wasComparing != value {
                       hapticTrigger.toggle()
                   }
               }
       }
       ```
       The `minimumDuration: 0.15` (150ms) per D-06 and Pitfall 3 (RESEARCH.md lines 422-430): fast enough for responsive toggling, slow enough to distinguish from pinch start.

    3. Combine gestures using `.simultaneously(with:)` per Pattern 4 (RESEARCH.md lines 330-353):
       ```swift
       private var combinedGesture: some Gesture {
           comparisonGesture.simultaneously(with: magnifyGesture)
       }
       ```

    4. Replace the existing `.gesture(magnifyGesture)` modifier (line 28) with `.gesture(combinedGesture)`. The simultaneous gesture composition allows both long-press and pinch to be recognized independently — no gesture conflict.

    5. Update the `Image(uiImage:)` in the preview group (line 23) to display either watermarked or original based on `isComparing`:

       This ternary: when long-pressing, shows `originalSourceImage` (falling back to watermarked `preview` if original isn't cached yet). When not pressing, shows watermarked `preview`.
