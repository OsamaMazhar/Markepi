  <action>
    Create `MarkepiScrollEdgeProtection.swift`.

    **Struct: `MarkepiScrollEdgeProtection<Header: View>`** (public, conforms to `ViewModifier`)
    - Generic over the header content type
    - `@ViewBuilder let headerContent: () -> Header` — the header view builder (typically `MarkepiPillBar`)
    - `@Environment(\.accessibilityReduceTransparency) private var reduceTransparency`

    `func body(content: Content) -> some View`:
    - Wrap in `ZStack(alignment: .top)`:
      - **Layer 1 (back):** `ScrollView(.vertical)` containing `content` with `.padding(.top, headerHeight + 16)` where `headerHeight` is a computed property measuring the header's approximate height (use `44` as the default — the pill bar with `.padding(4)` + segment padding `.padding(.vertical, 8)` ≈ 44pt). The `+16` provides additional breathing room so scrolled content doesn't start directly at the header edge.
        - Apply `.scrollClipDisabled()` to the scroll view (D-16: content renders beneath the header)
        - Apply `.allowsHitTesting(true)` to the scroll view itself (content is hittable when visible)
      - **Layer 2 (front):** `headerContent()` overlaid at `.top` alignment
        - Apply `.padding(.horizontal, 16)` and `.padding(.vertical, 8)` for outer spacing
        - Apply glass/material treatment using the `.modify {}` pattern:
          - iOS 26 + Reduce Transparency off: `.glassEffect(.regular, in: RoundedRectangle(cornerRadius: 20))`
          - Fallback: `.background(.ultraThinMaterial, in: RoundedRectangle(cornerRadius: 20))` (D-17: material itself provides the obscuring effect — no separate gradient or mask)
        - Apply `.padding(.top, 4)` for safe-area clearance
        - The header's glass backing naturally blurs content scrolling beneath it — the blur IS the scroll-edge effect (no separate `blur` modifier needed per D-17 and RESEARCH.md anti-pattern "Building a custom blur gradient")

    **Hit-testing (Pitfall 2 mitigation):** Because `.scrollClipDisabled()` allows content to render beneath the header, the content in the overlap zone should NOT intercept taps. The glass header naturally intercepts touches first because it's in the front ZStack layer. However, ensure the header has sufficient z-index by placing it second in the `ZStack`. No explicit `.allowsHitTesting(false)` needed on the content since the header layer's hit area covers the content overlap.

    **View extension: `.markepiScrollEdgeProtection(headerContent:)`** (public)
    - `func markepiScrollEdgeProtection<Header: View>(@ViewBuilder headerContent: @escaping () -> Header) -> some View`
    - Wraps `MarkepiScrollEdgeProtection(headerContent: headerContent)`
    - D-19: reusable modifier applicable to any scroll view with a glass/material header

    Remove the `.gitkeep` file from `ScrollEdge/` after creating the Swift file.
  </action>

| T-15-04 | Denial of Service (UX) | MarkepiPillBar — Dynamic Type overflow at large sizes | accept | Pill labels use `.markepiTypography(.pillLabel)` which maps to `.headline.weight(.medium)` — a system font style with automatic Dynamic Type.
