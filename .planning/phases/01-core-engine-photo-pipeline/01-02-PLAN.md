## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ImageWatermarkInput.pngData → ImageWatermarkRenderer | Untrusted PNG data from user-provided logo files enters Core Image rendering |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Denial of Service | ImageWatermarkRenderer | mitigate | Validate PNG data is non-empty before CIImage creation. CIImage(data:) handles malformed PNG gracefully (returns nil) → throw PipelineError.invalidImageData. |
| T-02-02 | Denial of Service | ImageWatermarkInput | mitigate | Validate scale is within 0.01–0.90 range. Extreme scale values (e.g., 100.0) would create enormous CIImage extents causing memory exhaustion. Reject with PipelineError.invalidScale. |
| T-02-03 | Information Disclosure | ImageWatermarkInput | accept | PNG watermark images are user-provided logos. They may contain embedded metadata (PNG tEXt chunks, etc.). This metadata is preserved in the watermark CIImage but does not propagate to the output photo's EXIF (only the base photo's extracted metadata is re-attached). Low risk — watermark PNG metadata is typically benign (software name, creation timestamp). |
</threat_model>
