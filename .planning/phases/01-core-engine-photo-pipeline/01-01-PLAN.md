- **Code Example: WatermarkEngine actor** (RESEARCH.md line 347-427) — buildFilterGraph method: normalize → build layers → composite → render → write

### Anti-patterns to avoid (RESEARCH.md §Anti-Patterns):
- NEVER use UIImage in the processing pipeline (strips metadata + HDR)
- NEVER create CIContext per operation (reuse actor-owned singleton)
- NEVER skip EXIF orientation normalization (causes double-rotation watermark misplacement)
- NEVER use UIImage.jpegData() for output (use CGImageDestination with source UTI)
- NEVER hardcode color space to DeviceRGB (pass source color space through)

### User decisions from CONTEXT.md:
- D-01: Ordered layer stack — watermarks composited in array order onto base image
- D-02: SF system fonts for text watermarks (UIFont.systemFont)
- D-09: Preserve source format (HEIC→HEIC, JPEG→JPEG) per CGImageSourceGetType
- D-10: Core formats: HEIC, JPEG, PNG
