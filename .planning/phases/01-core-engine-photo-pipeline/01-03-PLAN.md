         e. Convert to CIImage: `guard let ciImage = CIImage(image: uiImage) else { throw PipelineError.frameRenderFailed }`
         f. Return ciImage

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| EXIF metadata → DeviceMetadataProvider | Untrusted EXIF model string from user photos is formatted into attribution text |
| UIGraphicsImageRenderer → CIImage | White frame rendering crosses Core Graphics → Core Image boundary, potential for HDR clipping |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | DeviceMetadataProvider | accept | Device model extracted from EXIF TIFF model tag is user's own photo metadata. The attribution text "Taken by: iPhone 16 Pro" is displayed in output. This is intentional (the feature). Phase 2 UI should offer a toggle to hide metadata text per user preference. |
| T-03-02 | Denial of Service | WhiteFrameRenderer | mitigate | UIGraphicsImageRenderer operates on baseExtent.size which is bounded by the image dimensions already validated (≤100MP from Plan 01 input validation). Frame width ratio is clamped to 0.03–0.05 preventing extreme memory allocation. |
| T-03-03 | Elevation of Privilege | WhiteFrameRenderer | accept | NSAttributedString drawing for metadata text — no code execution path. Text content is either auto-generated from DeviceMetadataProvider (safe) or user-provided customAttributionText string (sanitized by NSAttributedString rendering). |
