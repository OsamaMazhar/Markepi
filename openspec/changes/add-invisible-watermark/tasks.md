## 3. Embedding (MarkepiCore)

- [ ] 3.1 Add the `InvisibleWatermarkProvider` protocol, `NoopInvisibleWatermarkProvider`, and a `TrustMarkPProvider` that takes model URLs. Encoding uses a centre-square crop, a 256² Lanczos downscale, RGBA8 sRGB, then the encoder. Decoding uses a centre-square crop from a `CGImageSource` thumbnail, a 224² resize, the decoder, BCH_5, then the payload validation from 2.1. Verify a macOS test decodes the probe's existing stego JPEG to `MKP7F3A`.
- [ ] 3.2 Implement the CI-graph composite from D4: a residual `CIImage` ×0.5, bilinear upscale to the centre square, the sRGB tone curve, and the three-line colour kernel. Strength is fixed at effective 1.25. Verify that on the 3024×2268 probe sample, PSNR is ≥ 46 dB, the delta outside the centre square is 0, and the result decodes.
- [ ] 3.3 HDR gate. Export a real HDR HEIC and an HDR JPEG with a gain map through the engine with the watermark on. Verify the gain map auxiliary data is present and unchanged in size and type (`CGImageSourceCopyAuxiliaryDataInfoAtIndex`), exiftool metadata is identical to the unwatermarked export, and the ID decodes. If the RGBAh path conflicts, implement the "skip watermark, keep HDR" fallback and test it.
- [ ] 3.4 Robustness test, ported from `wmtest_p.py`. Run the Swift embedder on 12 MP and 48 MP samples under q95, 1600/q60, 1080/q55, 1600/q80, screenshot-scale 1179/q80 and a 10 % crop. Verify all of these decode with a valid CRC, matching or beating the probe's 6/8. A 25 % crop must return no watermark or an invalid one, never a valid wrong ID.
- [ ] 3.5 Calibrate the PDQ threshold. Hash 30 exports against their re-encoded copies (from 3.4) and against 200 unrelated images. Verify the chosen threshold, starting at ≤ 31, gives a 0 % false-match rate on the unrelated set, and record the numbers in design.md.
